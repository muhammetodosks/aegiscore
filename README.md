# React Media - Advanced Windows Security System

**React Media** is a cutting-edge Windows security system that provides comprehensive protection through system-level monitoring and policy enforcement. This advanced security solution operates at the core of Windows to ensure maximum protection against modern threats.

## 🚀 Quick Start

**NO BUILDING REQUIRED** - Everything is pre-compiled and ready to use!

### Installation (3 Simple Steps)
1. **Download** the React Media package
2. **Right-click** on `BATUR_INSTALL.bat`
3. **Run as Administrator** and click "Yes" when prompted

That's it! React Media is now protecting your system.

### Removal (2 Simple Steps)
1. **Right-click** on `BATUR_CLEAN.bat`
2. **Run as Administrator** and type "CLEAN" when prompted

Your system will be completely restored to its original state.

## 🚀 Installation Guide

### 🎯 Pre-Installation Checklist
- [ ] **Administrator account** available
- [ ] **Windows 10/11** (64-bit) confirmed
- [ ] **Antivirus software** temporarily disabled (may conflict)
- [ ] **System backup** created (recommended)
- [ ] **All other programs** closed

### 📥 Step-by-Step Installation

#### Step 1: Download React Media
1. Download the latest React Media package
2. Extract to a folder (e.g., `C:\ReactMedia\`)
3. Navigate to the extracted folder

#### Step 2: Run Installation
1. **Right-click** on `BATUR_INSTALL.bat`
2. Select **"Run as administrator"**
3. **Click "Yes"** on the UAC prompt

#### Step 3: Follow Prompts
The installer will:
1. ✅ **Check administrator privileges**
2. 📋 **Display security policies**
3. ❓ **Ask for your consent**
4. 📁 **Create installation directory**
5. 📦 **Install security DLL**
6. 🔧 **Register system components**
7. 🛡️ **Activate security protection**
8. 🔒 **Lock security policies**

#### Step 4: Confirmation
You'll see:
```
==================================================
INSTALLATION COMPLETED SUCCESSFULLY
AegisCore is now active and protecting this system.
Emergency removal is always possible via BATUR_CLEAN.bat
==================================================
```

**🎉 Installation Complete!** Your system is now protected.

## 🧹 Removal Guide

### ⚠️ Important Notes
- **Administrator privileges required**
- **System will be fully restored**
- **No residue left behind**
- **Safe and reversible process**

### 📋 Step-by-Step Removal

#### Step 1: Run Cleanup
1. **Right-click** on `BATUR_CLEAN.bat`
2. Select **"Run as administrator"**
3. **Click "Yes"** on the UAC prompt

#### Step 2: Confirm Removal
Type **"CLEAN"** (exactly as shown) and press Enter:
```
Type CLEAN to continue: CLEAN
```

#### Step 3: Automatic Cleanup
The cleanup will:
1. 🚨 **Trigger emergency shutdown**
2. 🔄 **Terminate running processes**
3. 🗑️ **Clean registry entries**
4. 📁 **Remove installed files**
5. 📋 **Delete policy files**
6. 🧹 **Clean log files**
7. ✅ **Verify system restoration**

#### Step 4: Final Confirmation
You'll see:
```
==================================================
CLEANUP COMPLETE - SYSTEM RESTORED
==================================================
✔ All security hooks removed
✔ All policies unlocked
✔ All files deleted
✔ Registry cleaned
✔ No residue left

System is now in NORMAL state.
You may safely reboot if desired.
==================================================
```

**✅ Removal Complete!** Your system is back to normal.
